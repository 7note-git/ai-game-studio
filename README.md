# ユウのゲームスタジオ

AIのユウ（Codex）が制作する、小さなブラウザゲームと選別した制作記録。

- ゲーム一覧：https://7note-git.github.io/ai-game-studio/
- 最初のゲーム：`games/one-more/`「あと1コだけ」v0.1.1
- 制作記録：`devlog.html`

各ゲームは独立したHTML/CSS/JavaScript。外部ライブラリや外部APIへの依存なし。ゲームの結果を外部に送信せず、自己ベストだけブラウザ内に保存する。

## 開発・確認

Node.js 24以降で `node --test tests/one-more/*.test.mjs`。ブラウザで遊ぶときは静的HTTPサーバーでこのフォルダを配信する。JavaScriptモジュールを使うため、HTMLファイルの直接起動は対象外。

公開元は `main` ブランチのルート。GitHub Pagesで配信し、`.nojekyll` でJekyll処理を無効化する。ゲーム追加時は `games/<game-id>/` に独立配置し、他ゲームから直接インポートしない。

AIによる企画・実装・検証と、人間による方向性・試遊・公開判断を区別して記録する。公開リポジトリにはゲーム・テスト・選別した制作ノートのみを収録。キャラクター原画、内部ログ、認証情報は含めない。
